Folio

A local library that tells you when the repos, papers and docs you saved have changed.

You star a repo, and three months later it ships a breaking major release. You save a paper, and a heavily cited follow-up appears. Folio watches what you saved and tells you. It runs entirely on your machine.

View on GitHub Install

What it tracks

Repos

New major releases, plus repos that went stale or were archived.

Papers

Influential follow-up work, citation counts and linked code.

Docs

Pages that fall behind the latest version on PyPI or npm.

And a full read-later shelf

Search by meaning

Hybrid vector and keyword search across everything you save.

Saves everything

URLs, notes, PDFs, screenshots, watched folders and a browser extension.

Ask your library

Answers from your own items, with citations you can check.

Private by design

Local Ollama models. Your notes and files are never uploaded.

Install

You need Docker and Ollama.

ollama pull gemma2:2b
ollama pull nomic-embed-text
ollama pull gemma3:4b

git clone https://github.com/dataWizard7957/folio
cd folio
docker compose up -d

Then open http://localhost:5173. There is no hosted version, because Folio is meant to run on your own machine. See the README for Linux notes, running without Ollama installed, and development setup.

Models run locally. Folio only calls public APIs such as GitHub, arXiv and PyPI to look up the items you save.
