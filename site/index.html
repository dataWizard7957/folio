Folio

A private research memory for developers. Keep papers, repos, screenshots and notes on one local shelf, and find them by meaning.

View on GitHub

What it does

Semantic search

Hybrid vector and keyword search across everything you save.

Saves everything

URLs, notes, PDFs, screenshots, watched folders and a browser extension.

Understands developer content

Repo stars and releases, paper authors and citations, docs versions.

Update alerts

Major releases, stale repos, follow-up papers and outdated docs.

Ask your library

Answers from your own items, with citations you can check.

Runs locally

FastAPI, SQLite and Ollama models on your own machine.

Get started

Folio runs on your computer, so there is no hosted version. You'll need Python, Node.js and Ollama.

git clone https://github.com/dataWizard7957/Folio.git
cd Folio

Then follow the quick start.

Models run locally. Folio only calls public APIs such as GitHub and arXiv to look up the items you save.
