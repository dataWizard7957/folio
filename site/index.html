Install

Running in a few minutes

You need Docker and Ollama. Then open localhost:5173.

There's no hosted version: Folio is meant to run on your own machine. The README covers Linux, running without Ollama installed, and development setup.

# 1. Pull the local models
$ ollama pull gemma2:2b
$ ollama pull nomic-embed-text
$ ollama pull gemma3:4b

# 2. Start Folio
$ git clone https://github.com/dataWizard7957/folio
$ cd folio
$ docker compose up -d

Models run locally. Folio only calls public APIs such as GitHub, arXiv and PyPI to look up the items you save.
